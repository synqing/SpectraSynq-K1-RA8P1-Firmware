## Consumer and consequence

The existing Surface authors and saves one composition containing both boards,
palette/Edge relationships, musical conditioning, model targets and motion. Three
profiles select Travelling Dual Ribbons, Vertical Call and Answer, or Tension/Release
Bloom. They use existing publication, independent renderer instances and final output
adapters. Existing donor Bloom remains unchanged and separately selectable.

The point is recognisable material and deliberate space: a bounded multicolour call,
an identifiable journey and a weaker answer. No new analyser, broker or dashboard.
The whole-system benefit is that the scene is the actual consumer of musical events,
ML variation and authoring. Existing curated palettes and centre-origin geometry bind.

## Implemented behaviour

- Two scheduled ribbons per gesture, timestamp-based travel and finite trails. The
  outgoing tail clears before protected quiet. Incoming events while busy are discarded.
  Each launch captures an authored16-sample RGB palette span and reference strength.
  Return width, feather, travel and attenuation remain independently controlled.
- Bloom stores actual injected RGB on a25ms content clock, interpolated causally. Palette
  edits affect new material; history drains before travel settings change. Zero, one
  and two return trips use actual outward travel delay before the inward leg.
- One pair coordinator transfers palette identity and intent, never another board's
  completed image. Either board can call. Call/answer starts the answer at the outer
  position and travels inward; counter-motion starts its inward answer after a quarter
  of the outward travel plus the authored delay. Linked composition owns the answer
  and final inward reply; independent trip count applies to independent transport.
- Whole-board quiet excludes background/screensaver. Pair quiet holds completed
  outgoing tails until both participants clear, then applies the shared plateau before
  resuming retained returns. Material-only and wash-exempt scopes are explicit.
  Flowing Bloom obtains rest from completed phrase release/recovery and drained history.
- Existing body-event conditioning admits gestures. Raw valid level establishes quiet;
  low novelty alone is never silence. Existing board musical conditioning and response
  gain still shape scene strength. There is no queued burst after a protected gap.
- Rest/Establish/Develop/Tension/Release/Recover have dwell and distinct transitions.
  Automatic direction adjusts the next width, separation/recovery and Bloom injection.
  Manual hold, release and rest take precedence without cancelling travelling material.
  These are composition states, not inferred song sections.
- An optional selected candidate clock uses actual donor tempo frequencies, stable
  acquisition and switch hysteresis. Phase correction is continuous; stale evidence
  coasts for at most1500ms. Automatic phrase launches may wait at most250ms while idle;
  unlocked and initial gestures work immediately. This is a counted grid, not a downbeat.
- Fresh bounded model output influences width, palette distribution or return detail;
  phase-sensitive width is latched by transport. Stale model output falls back to the
  authored base. No instrument/emotion/section labels are claimed.

## Authoring and persistence

The existing Surface keeps draft, requested and active state distinct. Activity changes
admission/recovery; Space changes separation/quiet/recovery; Scale changes widths;
Movement changes travel/trail time. Macros never change brightness or physical gains.
Locks constrain edits and scoped variation; undo/redo covers the complete document.
Selecting a named profile configures both boards atomically in the draft and refuses
conflicting locks. Apply uses sequential targeted device transactions, with full
readback and explicit partial failure. It is not a two-board atomic wire transaction.

Keep saves both boards, palette/Edge relation and locks on the host. Saved composition
recall does not persist framebuffer/history or write device nonvolatile storage.
Motion/scene edits take effect at a completed gesture/history boundary. A linked
composition holds both active configurations until the full answer/reply finishes.

Wire profile6 adds fields45–63 and capability64, with424-byte state including requested
configuration and active scene/phase/pending/gesture/phrase/quiet status. Old negotiated
profiles remain supported; unsupported v6 must fail explicitly before exact fallback.
