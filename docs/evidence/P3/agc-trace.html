What sets Titan brightness?

The automatic gain control (AGC) does squeeze loudness, but neither v8 effect turns loudness into brightness. Colour comes from the music's harmony, and it switches from gold to red about six seconds before the drop, when the build's tonal section ends. Louder sound makes the trails fade faster. Red counts for much less brightness than gold. So the lower board gives out almost the same light in the drop (×0.93), while its luma falls to ×0.63.

Fact sheet

Answers to the four AGC questions

1. Follower type and timing

  • Peak, not RMS. drive = max|x| − 350 over each 96-sample frame (inhouse_audio.cpp:213, 226).
  • Updated per frame (7.5 ms; the first call uses 10 ms), not per sample (:228).
  • Rule. α = dt ÷ (τ + dt), with τ = 10 ms × (1 − r) ÷ r (:23–27).
  • Follower: attack 0.25 → τ 30 ms; release 0.005 → τ 1.99 s.
  • peak_scaled smoother: 0.65 → 5.4 ms; 0.15 → 57 ms.

2. Placement

Time domain, on raw frame peaks, beside the Goertzel bank and not before it. The spectrum has its own AGC (③). peak_scaled never feeds the Goertzel bank or the colour.

PDM → DMA → loud guard → ASRC 12.8 kHz → 96-sample frame → peak − 350 → follower → ÷ → smoother → peak_scaled

3. Donor level (×3.93 at the drop)

Computed in the donor Emotiscope analysis (emotiscope_port.cpp:372–383). Neither v8 effect reads it. The v8 path uses only the donor's PCM peak², and only to open or close the admission gate (composed_scene_runtime.h:26–33).

4. Other levelling stages and doctrine

  • Four adaptive stages: loud guard, peak AGC, spectral AGC, chroma normaliser.
  • Four gates: silence flag, noise gate, tonality gate, admission.
  • Fixed scalings: response gain, display brightness, shoulder, output 0.25.
  • CORE-ARCH-004 / ADR-006 (audio): not found in this repository, the workspace or shared memory. The ADR-006 that does exist covers governance policy publication. Not ported.
Limits
  • The replay is a model. The device's own microphone audio was never recorded, so the room recording (iPhone) stands in for it. The replay omits the donor admission gate and runs on the host, not the M85.
  • Lower-board replay fidelity is poor (ρ −0.05 / 0.23). Its verdict uses the device colour split.
  • The brief's citations point at a file this build doesn't run. product_effect_renderer.cpp:746/797/1326 is not compiled into this build (build_scalar.py:728). The v8 effects run in inhouse_waveform.cpp.
  • Earlier P2/P3 probes used the neighbouring palettes. They passed palette ids 32/39, but the device uses 31/38 (renderInhouse passes palette − 1). The probe is fixed; tempo and level results are unaffected.
